# @agent-harness/mobile

Mobile client (Capacitor) for agent-harness. Wraps `frontend/webapp/dist` in a native iOS/Android shell.

## Structure

```
mobile/
├── package.json
├── capacitor.config.ts    # App ID, Server URL, plugin config
├── tsconfig.json
├── src/
│   ├── app.ts             # Entry: plugin re-exports
│   ├── bridge/
│   │   └── register-plugins.ts  # Capacitor plugin registry
│   └── plugins/           # Native capability wrappers (interface + default impl)
│       ├── push-notification.ts
│       ├── deep-link.ts
│       ├── file-upload.ts
│       ├── biometric-auth.ts
│       └── offline-cache.ts
├── ios/                   # Generated by `cap add ios`
└── android/               # Generated by `cap add android`
```

## Build

```bash
# Build webapp + sync to native projects
pnpm --filter @agent-harness/mobile run build

# Open in Xcode / Android Studio
pnpm --filter @agent-harness/mobile run open:ios
pnpm --filter @agent-harness/mobile run open:android
```

## Architecture

- **Zero coupling**: mobile/ does NOT import from `access/server` or `backend/core`.
- All business logic lives in `frontend/webapp`; mobile only adds native capabilities.
- Plugins follow "interface + default implementation" pattern for testability.
- `capacitor.config.ts` points `webDir` to `../frontend/webapp/dist` (single source of truth).
