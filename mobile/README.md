# @agent-harness/mobile

Mobile client (Capacitor) for agent-harness. Wraps `frontend/webapp/dist` in a native iOS/Android shell.

## Structure

```
mobile/
├── package.json
├── capacitor.config.ts    # App ID, Server URL, plugin config, Deep Link scheme
├── tsconfig.json
├── .gitignore
├── README.md
├── REVIEW_CHECKLIST.md    # App Store / Play 审核材料
├── src/
│   ├── app.ts             # Entry: plugin re-exports
│   ├── bridge/
│   │   └── register-plugins.ts  # Capacitor plugin registry + lifecycle
│   └── plugins/           # Native capability wrappers (interface + default impl)
│       ├── push-notification.ts   # FCM/APNs 注册
│       ├── deep-link.ts           # piagent:// 路由解析
│       ├── file-upload.ts         # 相机/相册 → artifacts 上传
│       ├── artifacts-client.ts    # POST /api/artifacts 客户端
│       ├── biometric-auth.ts      # Face ID / 指纹快捷登录
│       └── offline-cache.ts       # TTL 缓存 + 网络状态监听
├── ios/                   # Generated by `cap add ios`
│   └── App/App/
│       ├── Info.plist     # Face ID + piagent:// scheme 已配置
│       └── Assets.xcassets/
└── android/               # Generated by `cap add android`
```

## Build

```bash
# Install deps
pnpm install --filter @agent-harness/mobile

# Build webapp + sync to native projects
pnpm --filter @agent-harness/mobile run build

# Open in Xcode / Android Studio
pnpm --filter @agent-harness/mobile run open:ios
pnpm --filter @agent-harness/mobile run open:android
```

## Deep Link Route Table

| Deep Link | Target Tab | Description |
|---|---|---|
| `piagent://chat` | 对话 | Chat list |
| `piagent://chat/:sessionId` | 对话详情 | Specific session |
| `piagent://plan` | 计划 | Plan board |
| `piagent://plan/:planId` | 计划详情 | Specific plan |
| `piagent://artifact` | 档案 | Artifact library |
| `piagent://settings` | 设置 | Settings |

## Architecture

- **Zero coupling**: mobile/ does NOT import from `access/server` or `backend/core`.
- All business logic lives in `frontend/webapp`; mobile only adds native capabilities.
- Plugins follow "interface + default implementation" pattern for testability.
- `capacitor.config.ts` points `webDir` to `../frontend/webapp/dist` (single source of truth).
- Token stored in `@capacitor/preferences` (iOS Keychain / Android EncryptedSharedPreferences) — NOT localStorage.
