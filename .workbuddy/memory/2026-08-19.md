- **Bash 沙箱坑（重要）**：`Write` 工具写入的文件在后续 `Bash` 调用里有时不可见（fs 命名空间隔离），但 `cat > file <<'EOF'` 在**同一 Bash 调用**内创建并运行则可靠——探针类验证务必用 heredoc 内联，勿依赖 Write→Bash 跨工具可见性。另：`&` 后台化若与 `cd &&` 写在同一行会连 `cd` 一起丢进后台子 shell，导致前台 cwd 错位；`cd` 须独占一行。
