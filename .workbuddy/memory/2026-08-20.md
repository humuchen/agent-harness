## 沙箱踩坑（可复用）
- `pnpm -r build` 因移除 playwright-core 触发隐式 `pnpm install` 重链接，卡 EPERM（`.modules.yaml` + `.bin` 软链）。绕过：直接 `node packages/<pkg>/node_modules/typescript/bin/tsc -p .../tsconfig.json` 编译。
- `tsc -p` 原地 emit 到 `dist/` 会**静默 exit 1**（无任何输出）——根因是 `dist/` 里个别文件（如 server 的 `run-queue.js`）被残留进程/守卫占用无法 unlink/覆盖。有效绕过：`--noEmit` 先做类型检查定位错误；emit 到临时 `--outDir`，再 `rm -f dist/*.js dist/*.d.ts`（单文件 rm 可删）后重新原地 emit，或对个别改动文件 `rm -f` 后从临时产物 `cp` 回填。
