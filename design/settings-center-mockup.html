方案 B · 顶部平铺 Tab 本次方向

分组导航不再竖排在侧栏、也不再横滑，而是 平铺在顶部：桌面为一行五等分 Tab（图标 + 全名）， 移动为五等分网格（图标在上、短名在下）。全部一屏可见、无滚动、无二级跳转；切换即换内容区。 从「我的 → 设置」进入，顶栏「‹ 返回」回到「我的」。

✓所有分组一屏平铺、零横滑、零溢出菜单，入口永不隐藏
✓桌面 / 移动共用同一「顶部平铺」范式，仅列数与图标朝向随断点变化，心智一致
✓内容区整宽（去掉 196px 侧栏），表单更舒展；沿用「我的」页令牌
✗分组增多（> 6）时横排会变挤，需降级为两行网格 —— 当前 5 组无压力

📐 方案 B 设计说明

类型与参照：设置页 → 顶部平铺 Tab + 单列内容（Tab 采用等分平铺，不用横滑、不用侧栏）。
平铺规则：桌面 flex:1 1 0 五等分（图标在左、全名在右）；移动 grid-template-columns: repeat(5,1fr) 五等分网格（图标在上、短名在下）。分组一屏可见、无滚动。
尺寸间距：以卡片行（13.5px 正文 / 12px 行内距 / 30px 图标盒）为锚点，Tab 高 36px、图标 15–17px，与行内元素同一档；内容区整宽。
主操作：每屏仅 API Key「保存」为强调实底；Tab 选中态用 accent-soft 底 + accent 字，非实心强调色，不抢内容。
辅助入口收敛：「‹ 返回」为中性描边小按钮；行内删除用 danger 文字；chevron 表层级。
图标来源：Lucide 线型隐喻（用户 / 钥匙 / 滑块 / 调色板 / 信息），stroke 1.8，同屏同库同风格。
落地建议：新建 ah-settings-center 组件（顶部平铺 Tab + 内容区切换），「模型与密钥」分区直接复用现有 ah-provider-key-settings； 由 ah-goto detail:'settings' 进入，可选携带 group 参数定位分组。

* 设计稿基于 Agent Harness dark 令牌（#0B0E14 / accent #2997FF），浅色主题由 --ah-* 令牌自动映射，无需单独适配。
