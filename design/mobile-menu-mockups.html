底部 Tab + 顶部子导航 混合两级

底部 4 Tab 只承载一级域：工作台 / 对话 / 资产 / 我的。 高内聚的域（如「资产」= MCP + 技能 + 数据源 + 插件）用顶部横向分段做二级切换， 「我的」收纳观测 / 治理 / 设置。平衡了深度与广度。

✓一级导航极简（4 个），域内二级切换零页面跳转
✓与桌面侧边栏「宽屏显示全部」形成天然互补
✗需要引入「聚合页」（资产页、我的页），组件与路由改造偏多
✗二级项超过 5 个时分段放不下，仍需降级到「更多」

🎯 落地进度（方案 A · 已实现）

第一步：TABS 分组 —— TABS 增加 group 字段（使用/能力/观测/治理），移动抽屉按组渲染分隔标题；桌面侧边栏忽略 group 保持扁平。
第二步：移除顶栏头像 —— 顶栏只留 ☰ + 标题 + LLM 状态；账户菜单迁入「me」视图，用 ah-user-menu standalone 承载用户卡片 / 改密 / 设置 / 退出 / 版本号。
第三步：底部 Tab 栏 —— .mobile-tabbar（≤760px 显示），5 个 Tab 走 setMobileTab() → setTab()，切走时收起抽屉。
第四步：抽屉 + 手势 —— 点击 ☰ 或左屏边缘右滑（touchstart≤16px、touchmove dx≥40px）打开左滑抽屉；点击遮罩/切 Tab/ Esc 关闭；抽屉底固定「主题」+「我的」快入。
第五步：插件收敛 —— 动态插件 Tab 按 category 进入对应分组或「插件」Tab。
