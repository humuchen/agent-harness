## 关键修正（执行中踩坑）
1. **鉴权变量**：本仓库运行期鉴权走 `OPEN_API_KEY`（admin 逃生通道），**不是** `UI_AUTH_TOKEN`；首次用错导致 `/api/run` 401，改 env 后通过。
2. **测试 require 路径**：`plugins/memo/test/*.test.cjs` 相对 core 应为 `../../../backend/core/dist`，初版写成 `../../` 报错，已修正。
3. **dist 命名导出**：`registerNoteTools/memoServerExtension/memoBoardView` 原仅在子模块导出，测试 require `dist/index.js` 取不到；已在 `index.ts` 补 named re-exports。
4. **测试笔误**：`assert.equal(deleted.deleted,...)` 应为 `del.deleted`（变量名），已修正。
5. **core 测试断言**：新增默认技能后 `defaultSkills 提供 N 个` 断言需同步 +1。
