2. 版本 / 依赖解析流图（Phase 4）

flowchart TD
  A["安装 / 升级请求
manifest 或 range"] --> B{"body.manifest
且 id 匹配?"}
  B -->|是| C["采用请求体 manifest"]
  B -->|否, 有 PLUGIN_REGISTRY_URL + version| D["client.index -> resolveVersion"]
  D --> E{"range 类型"}
  E -->|latest 或缺省| F["取语义版本最高
cmpVersion"]
  E -->|"^x.y.z"| G["同主版本号最高"]
  E -->|精确版本| H["精确相等
否则 throw"]
  C --> I{"dependencies[]
全部已 install?"}
  H --> I
  F --> I
  G --> I
  I -->|否| J["throw: missing plugin"]
  I -->|是| K["resolveDependencies 通过"]
  K --> L{"upgrade?
manifest.id == id?"}
  L -->|否| M["install -> 标记 disabled"]
  L -->|是| N["throw: id mismatch"]
  M --> O{"原 state = enabled?"}
  O -->|是| P["disable -> 替换 manifest -> register
热插拔, 不重启"]
  O -->|否| Q["仅替换 manifest, 标记 disabled"]
  P --> R["isolation: manifest.isolation
-> resolveIsolationBackend"]
  Q --> R
  R --> S["none / local / os / container"]
