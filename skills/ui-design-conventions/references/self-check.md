# 交付前自查清单

实现完成后逐项勾选。任一项不通过 → 改完再交付。
（复制本清单到回复里逐条打勾，作为交付说明的一部分。）

---

## A. 类型与参照

- [ ] A1 已确定界面类型（后台 / 表单设置 / 文档 / 编辑器 / 对话 / 移动 H5），并按该类型行业惯例起步
- [ ] A2 能说出 1-2 个参照产品，界面气质与参照一致
- [ ] A3 没有为了「有设计感」而偏离该类型的惯例

## B. 尺寸与间距

- [ ] B1 找到了同屏信息最密的**锚点元素**，记录了它的字号 / 行高 / padding
- [ ] B2 新元素相对锚点浮动 ≤ 1 档（约 2-4px），最多 2 档
- [ ] B3 同屏字号种类 ≤ 4 种
- [ ] B4 页面标题 ≤ 24px（工具类界面）
- [ ] B5 控件高度符合平台习惯：桌面 28-36px / 移动端触控 ≥ 44px
- [ ] B6 组间距 > 组内间距（分组靠间距，不靠边框色块）
- [ ] B7 圆角：控件 4-8px / 卡片 8-12px，> 16px 有理由
- [ ] B8 没有为了「更清楚」主动放大任何元素

## C. 辅助入口不抢视觉中心

- [ ] C1 第一眼视线落在**主内容或主操作**上，不是落在设置 / 开关 / 工具按钮上
- [ ] C2 全屏 primary（实心强调色）按钮 ≤ 1 个
- [ ] C3 辅助入口是中性色（次级文字色），非强调色
- [ ] C4 行内操作默认低对比，hover / focus 时才显形
- [ ] C5 同位置 ≥ 3 个次要操作已收进 `⋯` 溢出菜单
- [ ] C6 辅助入口没有：实底色块、边框、阴影、加大字号、强调色

## D. 图标

- [ ] D1 每个常见功能都用了**通用隐喻**（对照 `icon-metaphors.md` 映射表）
- [ ] D2 无语义错配（齿轮≠筛选、×≠删除、铅笔≠新建）
- [ ] D3 全站同一图标库、同一风格、同一线宽（无混用）
- [ ] D4 自定义图标已通过前置检查（库里确实没有），且主体轮廓是通用符号变体
- [ ] D5 图标尺寸与相邻文字匹配（14px 文字→16px 图标）
- [ ] D6 已做**光学对齐**：方形/满格图标缩小 1-2px，视觉面积一致
- [ ] D7 纯图标按钮都有 `aria-label` + tooltip
- [ ] D8 识别度存疑的图标已补文字标签（尤其删除 / 清空 / 重置）
- [ ] D9 图标颜色用 `currentColor`，跟随文字色

## E. 层级表达

- [ ] E1 层级主要靠**位置 + 分组 + 留白**建立
- [ ] E2 分隔线 1px、低对比
- [ ] E3 强调色面积 < 5%，只给主操作与选中态
- [ ] E4 没有靠加粗 / 放大 / 加色块来「强调」
- [ ] E5 把次要元素调弱一档，比把主要元素调强一档用得更多

## F. 装饰性视觉

- [ ] F1 静态容器用 1px 边框，**无阴影**；阴影只用于浮层（dropdown / popover / dialog）
- [ ] F2 无装饰性渐变（渐变背景 / 渐变文字 / 渐变边框）
- [ ] F3 无厚边框（常规 1px；仅 focus-visible / selected 用 2px）
- [ ] F4 无大圆角（> 16px 需理由）
- [ ] F5 无营销页式布局（巨幅 hero / 超大标题 / 居中巨型 CTA / 三段式特性卡）
- [ ] F6 无多层阴影、彩色阴影、扩散半径 > 32px 的阴影

## G. 状态覆盖

- [ ] G1 交互元素有 `default / hover / active / focus-visible / disabled / loading / selected`
- [ ] G2 `focus-visible` 有可见 ring（未 `outline: none` 后不补）
- [ ] G3 数据区有 `loading / empty / error`，文案是人话
- [ ] G4 `empty` 状态带一个主操作；`error` 状态带重试
- [ ] G5 动效 120-200ms，仅 opacity/transform，`prefers-reduced-motion` 下降级

## H. 工程侧

- [ ] H1 无硬编码颜色，全部走项目既有设计令牌 / CSS 变量
- [ ] H2 深浅两套主题都已适配并校准（暗色下降低强调色饱和、阴影换边框）
- [ ] H3 正文对比度 ≥ 4.5:1，次要文字 ≥ 3:1
- [ ] H4 窄屏（< 640px）下布局不塌缩：表单单列、表格横向滚动
- [ ] H5 长文 / 表单栏宽受控（阅读 680-760px、表单 560-720px）

## I. 同屏对比收敛（最终关）

- [ ] I1 已列出同屏所有元素清单
- [ ] I2 新元素与锚点在字号 / 色重 / 装饰 / 留白四个维度逐一对比过
- [ ] I3 回答了：第一眼视线落在新元素上吗？（应该不会）
- [ ] I4 回答了：把新元素删掉，是缺功能还是只缺装饰？（只缺装饰 → 删掉或大幅弱化）
- [ ] I5 回答了：缩小一档 / 去掉背景 / 换成中性色后还能认出来吗？（能 → 已这么做）
- [ ] I6 任一维度超一档 → 已降一档并重跑对比
- [ ] I7 设置 / 开关 / 工具按钮单独过了 C 组检查

---

## 快速自检（30 秒版）

时间紧时至少回答这 4 个问题：

1. 第一眼看到的是主内容，还是某个按钮/色块？
2. 同屏最扎眼的元素，删掉会缺功能吗？
3. 每个图标不给文字，能 2 秒猜对吗？
4. 任何元素比它旁边最密的元素大两档以上吗？

任一答案为「否/会/猜不对/是」 → 回去收敛。
