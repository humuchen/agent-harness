# 尺寸与间距参考区间

> **用法**：这是校准用的量尺，不是必须遵守的规格。上下文（界面类型 / 信息密度 / 平台 / 频率 / 层级）压过表格。
> 定值的正确姿势是「锚点法」（见下），不是抄表。

---

## 1. 锚点法（优先于任何数值表）

```
1) 找锚点  → 同屏信息最密的元素（表格行 / 列表项 / 正文段落）
2) 记基准  → 它的 font-size、line-height、padding、color-weight
3) 定其它  → 只允许在锚点上下浮动 1 档（约 2-4px）
4) 设上限  → 浮出 2 档以上即破坏密度，收敛 1 档
```

**为什么**：统一规格表在密度不一致的界面上必然失效——后台表格用 16px padding 会显得空，文档阅读用 8px 会显得挤。锚点法让间距自动跟随当前界面的真实密度。

**正例**：表格行高 32px、行内 padding 6px 10px → 同屏工具栏按钮高度 28px、页面标题 20px、卡片 padding 12px。全部围绕 32px 这个锚点。
**反例**：表格行 32px，但页面标题 32px、工具栏按钮 40px、卡片 padding 24px。三个元素全部脱离锚点 → 界面被撕成两种密度。

---

## 2. 分界面类型参考区间

| 界面类型 | 正文/表格字号 | 行高 | 控件高度 | 内容区 padding | 栅格 gutter | 圆角 |
|---|---|---|---|---|---|---|
| 数据后台 / 表格 | 13-14px | 1.5 | 28-32px | 12-16px | 8px | 4-6px |
| 编辑器 / Canvas | 13px | 1.5 | 26-30px | 8-12px | 8px | 4-6px |
| 表单 / 设置 | 14px | 1.5 | 32-36px | 16-20px | 12px | 6-8px |
| 对话 / 消息 | 14-15px | 1.6 | 32-36px | 12-16px | 8-12px | 8-12px（气泡） |
| 文档 / 阅读 | 15-16px | 1.7 | 32px | 20-24px | 16px | 6px |
| 仪表盘 / 卡片墙 | 13-14px | 1.5 | 32px | 16px | 12-16px | 8-12px |
| 移动端 H5 | 14px | 1.5 | 44px（触控） | 16px | 12px | 8px |
| 落地页 / 营销 | 16px | 1.6 | 44-48px | 24-32px | 24px | 8-16px |

---

## 3. 行高与行长

| 内容 | line-height | 说明 |
|---|---|---|
| 密集表格 / 列表 | 1.4-1.5 | 行高 = 字号 × 1.5，再叠加 padding 得行高 |
| 正文（UI） | 1.5 | 默认值 |
| 长文阅读 | 1.7-1.75 | 窄栏 + 大行距 |
| 标题 | 1.2-1.3 | 字号越大行高比越小 |

**行长**：单行最优 45-75 字符（中文约 30-40 字）。
- 长文阅读容器 680-760px
- 表单 560-720px
- 表格 / 列表可满宽
- 超出栏宽时必须换行，不要靠横向滚动读正文

---

## 4. 触控与点击区

| 平台 | 最小触控区 | 说明 |
|---|---|---|
| iOS / 移动端 | 44×44pt | 视觉可以小，热区不能小（用 padding 或伪元素扩热区） |
| Material / Android | 48×48dp | 同上 |
| 桌面常规 | 28-36px 高 | 按钮最小高度 28px |
| 桌面密集（工具条、表格行内） | 24-28px | 允许图标按钮 24×24，纯图标 + tooltip |

**视觉尺寸 ≠ 热区尺寸**：图标看着 16px，按钮热区可以是 28px（padding 6px）。不要为了让热区达标而把图标放大。

---

## 5. 字号阶梯（同屏 ≤ 4 种）

| 层级 | 字号 | 用途 |
|---|---|---|
| 页面标题 | 18-24px | 工具类界面上限 24px；超过即营销页化 |
| 区块标题 | 14-16px | 通常加 500/600 字重，不加更大字号 |
| 正文 / 表格 | 13-14px | 锚点 |
| 辅助文字 | 12px | 时间戳、说明、占位符、角标 |

**同屏字号种类超过 4 种 → 合并相近的两档。**
不要为了区分层级而增加第 5 种字号，改用字重（400/500/600）或颜色。

---

## 6. 间距阶梯

基于 4px 基准网格（比 8px 更灵活，8px 是其子集）：

```
2   4   6   8   12   16   20   24   32   40   48
```

| 用途 | 取值 |
|---|---|
| 图标与文字间隙 | 4-6px |
| 控件内 padding（垂直） | 6-8px（密集）/ 8-10px（常规） |
| 控件内 padding（水平） | 8-12px（密集）/ 12-16px（常规） |
| 同组内元素间距 | 4-8px |
| 表单项之间 | 16-20px |
| 区块之间 | 24-32px |
| 页面级留白 | 16-24px（后台）/ 24-32px（文档） |

**组间距必须 > 组内间距**，这是分组的唯一手段（不靠边框、不靠色块）。

---

## 7. 圆角

| 元素 | 圆角 |
|---|---|
| 按钮、输入框、选择器 | 4-8px |
| 卡片、面板 | 8-12px |
| 模态 / Dialog | 12-16px |
| 标签 / 徽章（胶囊） | 999px 或 4px |
| 头像 / 圆形图标按钮 | 50% |

**> 16px 需要明确理由。** 常见误用：给按钮用 999px 全圆角导致按钮看起来像胶囊药片、给标签用 12px 圆角导致不像标签。

---

## 8. 阴影

| 场景 | 阴影 |
|---|---|
| 静态容器（卡片、面板、表格） | **不用阴影**，用 1px 边框 |
| hover 抬升 | `0 1px 3px rgba(0,0,0,.08)` 或仅加深边框色 |
| 浮层（dropdown / popover / tooltip） | `0 4px 12px rgba(0,0,0,.10)` |
| 模态 / Dialog | `0 8px 32px rgba(0,0,0,.16)` |

**禁止**：多层阴影叠加、扩散半径 > 32px、彩色阴影、给静态卡片加阴影（卡片就应该平贴在背景上）。

---

## 9. 边框

- 常规边框 **1px**，颜色用边框令牌（低对比中性色）。
- **2px 只用于 focus-visible ring 和 selected 状态**。
- 不要用边框做分组（用间距），不要用粗边框强调（用颜色或位置）。
- 表格：优先横向分隔线（1px），不要全包边框网格；不用竖线。

---

## 10. 颜色用量

| 用途 | 占比建议 |
|---|---|
| 中性色（背景、边框、正文） | 80%+ |
| 次级文字 / 图标 | 剩余主体 |
| 强调色（主操作、选中、链接） | **< 5% 面积** |
| 语义色（success/warn/error） | 仅状态出现时 |

**唯一强调色原则**：一屏一个强调色（主操作）。多个元素争抢强调色 = 没有层级。

---

## 11. 动效

| 项目 | 取值 |
|---|---|
| 微交互（hover / 展开） | 120-160ms |
| 面板 / 抽屉 | 180-240ms |
| 缓动 | `cubic-bezier(.4,0,.2,1)`（标准）或 `ease-out` |
| 可动画属性 | 仅 `opacity` / `transform` |
| 降低动效 | `@media (prefers-reduced-motion: reduce)` 下全部降为 0ms |

不要给列表项加交错入场动画（工具类界面），不要给数据更新加弹跳。
