## 2. 易错对照（高频踩坑）

| ❌ 错误 | ✅ 正确 | 原因 |
|---|---|---|
| 用齿轮表示「筛选」 | `filter`（漏斗） | 齿轮已被占用为「设置」 |
| 用 × 表示「删除」 | `trash-2` | × 语义是关闭/取消，误点代价不同 |
| 用 × 表示「清空输入」 | `circle-x` 或 `x`（小号） | 清空要用弱化版，别与删除同级 |
| 用星标表示「保存」 | `save` | 星标 = 收藏 |
| 用箭头表示「展开」 | `chevron-down` | chevron 表层级，arrow 表方向 |
| 用铅笔表示「新建」 | `plus` | 铅笔 = 编辑已有 |
| 用垃圾桶表示「清空列表」 | `eraser` / 文字「清空」 | 垃圾桶 = 删除记录，语义过重 |
| 用三点表示「设置」 | `settings`（齿轮） | 三点 = 更多操作 |
| 用铃铛表示「消息列表」 | `message-square` | 铃铛 = 通知/提醒 |
| 用闪电表示「快速操作」 | 直接用文字或 `zap` 配文字 | 闪电语义模糊，必须配文字 |

## 3. 图标使用细则

### 风格统一（同屏强制）

- 同一图标库、同一风格变体（outline / solid / duotone 不混用）。
- 同一线宽（Lucide 默认 2 → 全站 2；Material Symbols 默认 1.5-2 → 全站一致）。
- 同一端点形状（round / square 不混用）。
- 同一视觉尺寸网格（24×24 或 20×20，不混用）。

### 尺寸

| 相邻文字 | 图标尺寸 |
|---|---|
| 12px（辅助） | 14px |
| 13-14px（正文） | 16px |
| 16px（小标题） | 18-20px |
| 20px+ | 24px |

### 光学对齐（最常被忽略）

同为 16px 的图标，视觉大小并不相同：

- **视觉偏大**：`square`、`image`、`layout-dashboard`、`grid`、`terminal`（方形/满格轮廓）
- **视觉偏小**：`play`、`chevron-*`、`arrow-*`、`plus`（三角/细长轮廓）

处理：方形/满格类图标缩小 1-2px（或减 1px 内边距），细长类可保持或 +1px。目标是**视觉面积一致**，不是外框尺寸一致。

### 可访问性

- 纯图标按钮 → 必须有 `aria-label` + `title` / tooltip。
- 装饰性图标（仅伴随文字）→ `aria-hidden="true"`。
- 图标颜色跟随文字色（用 `currentColor`），不要独立设色。

### 识别度兜底

自问：不给文字，用户 2 秒内能猜对吗？

- 猜得对 → 纯图标 + tooltip。
- 猜不对 / 存疑 > 20% → **图标 + 文字**（如「导出」「批量删除」）。
- 关键破坏性操作（删除、清空、重置）→ **必须带文字**，不能只靠图标。

## 4. 自定义图标规范

### 前置检查（必答）

1. 这个功能在 Lucide / Heroicons / Material Symbols / Phosphor / Feather 里有现成图标吗？
   → **有就用现成的**，不因为「想统一风格」或「想更有辨识度」而自创。
2. 现成图标只是风格不符？→ 换库或用同名图标的其它变体，仍不自创。
3. 确实是产品特有对象（自家 logo、特有实体类型）？→ 才考虑自创。

### 自创硬性要求

| 要求 | 标准 |
|---|---|
| 网格 | 与所用库同网格（通常 24×24），保留 2px 安全边距 |
| 线宽 | 与所用库完全一致（如 Lucide = 2px） |
| 端点 / 连接 | round/square/miter 与库一致 |
| 圆角半径 | 与库一致 |
| 光学尺寸 | 视觉面积与同屏其它图标相当（见上文光学对齐） |
| 轮廓来源 | 必须是**通用符号的可识别变体**，不是抽象几何 |

### 变体构造法（正确姿势）

以「导出为 PDF」为例：

- ✅ 通用下载箭头（向下箭头 + 托盘）+ 右下角 PDF 文档轮廓 → 用户先看到「下载」，再看细节。
- ❌ 抽象的三条曲线或自创符号 → 无识别基础。

**判据**：遮住自定义部分，剩下的主体仍是通用符号 → 合格。遮住后是抽象几何 → 不合格。

### 上线复核

- [ ] 在所用库的网格与线宽下绘制
- [ ] 视觉面积与同屏图标一致
- [ ] 主体轮廓是可识别的通用符号
- [ ] 16px 小尺寸下仍可辨认（缩到 16px 看是否糊成一团）
- [ ] 配了 `aria-label` 或文字标签
- [ ] 找人盲测：不给文字，2 秒内能说出功能吗

## 5. 图标库选择建议

| 库 | 风格 | 适用 |
|---|---|---|
| **Lucide** | 24×24 / 2px / 线性 | 通用首选，覆盖面广，中性克制 |
| **Heroicons** | 24×24（outline/solid 两套） | 现代 SaaS，与 Tailwind 生态契合 |
| **Material Symbols** | 可变字重 / 可变填充 | 需要考虑 Google 生态一致性 |
| **Phosphor** | 多字重（Thin→Bold） | 需要更多层次时 |
| **Feather** | 24×24 / 2px | 极简项目 |
| **系统图标**（SF Symbols / Fluent / Material You） | 平台原生 | 做原生 App 或强平台一致性时 |

**混用禁令**：一个界面里出现两个库的图标，即使风格相近，也会造成线宽、圆角、光学尺寸的细微不一致，视觉上立刻显脏。确定一个库后全站统一。
