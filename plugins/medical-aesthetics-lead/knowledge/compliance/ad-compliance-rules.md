# 医美广告合规规则（对外话术 / 文案 / 报告必须遵守）

> 医美属于医疗广告，监管严格。Agent 在生成任何**面向客户/公域**的文案、活动话术、报告结论中的表述时，
> 必须先读本文件，并在输出前用 `risk-lexicon.json` 自检；命中风险词必须替换或删除。

## 一、核心禁令（摘要）

1. **不得**对功效、安全性作断言或保证（如"永久""无副作用""保证见效"）。
2. **不得**说明治愈率、有效率，或用"根治""药到病除"等表述。
3. **不得**与其他机构/产品作比较（"比 XX 更好""唯一"）。
4. **不得**利用患者、医务人员、广告代言人名义或形象作推荐证明（含术前术后对比诱导）。
5. **不得**使用绝对化用语（"最""第一""国家级""顶级"）。
6. **不得**宣传未经审批的诊疗科目或违禁项目（如非合规的溶脂/线雕等依法规判定）。
7. 涉及医疗行为（注射、光电、手术）须提示「由合规机构执业医师操作」。

## 二、话术替换表（命中 → 建议替换）

| 风险表述 | 风险类型 | 建议替换 |
|----------|----------|----------|
| 永久 / 永远有效 | 保证性 | 删除，或"效果可维持一段时间" |
| 100% / 百分百 / 完全 | 保证性 | 删除绝对化措辞 |
| 无副作用 / 零风险 / 绝对安全 | 保证性 | "一般在规范操作下耐受良好" |
| 根治 / 治愈 | 治愈率 | 删除，改为"改善/调理" |
| 最 / 第一 / 顶级 / 国家级 | 绝对化 | 删除，或"较受关注""本地口碑较好" |
| 一针见效 / 当天见效 | 夸大 | 删除，改为"通常需按疗程" |
| 保证 / 承诺 / 签约治疗 | 保证性 | 删除，改为"可制定个性化方案" |
| 唯一 / 独家 | 比较 | 删除或核实后谨慎表述 |
| 真人案例 / 术前术后对比 | 代言 | 删除（禁止患者名义证明） |
| 名医亲诊 / 专家保证 | 代言/保证 | 核实资质后仅陈述客观事实 |

## 三、自检流程（Agent 输出前）

1. 生成对外文案/话术/报告表述。
2. 调用 `risk-lexicon.json` 词表逐条匹配。
3. 命中 → 按 `suggestion` 替换或删除；`severity: high` 必须处理。
4. 无法确认合规时，标注「建议法务复核」而非直接对外发布。

## 四、对内分析 vs 对外输出

- **对内分析**（经营指标、ROI、分层）不受上述禁令限制，但涉及客户隐私须脱敏（见 `data/` 已 `name_masked`）。
- **对外输出**（活动文案、客户话术、宣发报告）必须过合规自检。
